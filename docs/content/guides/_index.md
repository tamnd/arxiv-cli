Each guide is built around a job rather than a command.

- [Searching](/guides/searching/) covers the query grammar, the field flags, and the seven fields that live only in the search UI.
- [Reading a paper](/guides/reading-a-paper/) walks one paper through all four depths and shows what each one adds.
- [Browsing and following](/guides/browsing/) is listings, feeds, authors and categories.
- [Building a dataset](/guides/building-a-dataset/) is crawling into a store, querying it and exporting it.
- [Citing](/guides/citing/) is BibTeX and the six other formats.
- [Serving](/guides/serving/) is the HTTP and MCP surfaces.

They all assume you have run the [quick start](/getting-started/quick-start/).
