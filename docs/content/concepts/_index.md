Five pages, and they build on each other.

[Surfaces](/concepts/surfaces/) is the twelve places arXiv publishes, and what each one is uniquely good for.
[Planes](/concepts/planes/) is the two paces those places are read at, which is where cost comes from.
[Depth](/concepts/depth/) is the knob that decides how many surfaces one read crosses.
[Records](/concepts/records/) is the shape of what comes back, and the envelope that says where each field came from.
[The graph](/concepts/graph/) is what happens when reads are turned into claims, stored and walked.

Each page has a command that prints the same thing the page describes, because a table the binary carries cannot go stale the way a paragraph can.
