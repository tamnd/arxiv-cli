What shipped in each release, newest first.

Every tagged version builds the same set of artifacts: archives for Linux, macOS, Windows and FreeBSD, Linux packages as deb, rpm and apk, a multi-arch container image on GHCR, and entries for the package managers.

Binaries are pure Go with cgo off, so there is nothing to install alongside them.
